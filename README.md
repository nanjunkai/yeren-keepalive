# yeren-keepalive

定时探针仓库：每隔几分钟向一个**私有服务**的健康检查接口发一次轻量请求，
用于保持该服务处于唤醒状态，避免它在长时间无访问时被平台回收。

## 工作机制

- **触发**：`schedule`（每 5 分钟）为主，另留手动 `workflow_dispatch` 便于测试
- **服务地址**：存放在仓库 Secret `PING_URL` 中，**不写入本仓库的任何文件**
- **防自动停用**：每天生成一次空提交，避免仓库 60 天无活动导致定时任务被禁用

## 说明

本仓库不包含任何业务数据、凭证或监控内容。公开可见的只有本说明与
`.github/workflows/` 下的工作流文件，其中仅含占位符，不含真实域名与口令。

> 该工作流只做一件事：向配置好的地址发一次 HTTP 请求并检查返回 200。
